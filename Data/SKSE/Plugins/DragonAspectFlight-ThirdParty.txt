Dragon Aspect Flight 1.8.1 - third-party animation attribution
================================================================

Neutral flight pose
-------------------

  Flying Mod Beta
  Original author: porroone
  Skyrim SE/AE conversion credit: DimitriyKostov
  Original: https://www.nexusmods.com/skyrim/mods/15775

The bundled flight-idle donor was obtained from the credited Flying Mod OAR
set distributed with More Draconic Aspect Can Fly. It is redistributed here
under the animation's open permissions; Dragon Aspect Flight does not claim
authorship.

Aerial melee animations
-----------------------

  Jumping Attack
  Author: NickNak
  Nexus: https://www.nexusmods.com/skyrimspecialedition/mods/68043

NickNak's published permissions allow redistribution, modification,
conversion, and use in other mods with credit. Only the generated OAR paths
needed by Dragon Aspect Flight are installed; the repository-only source set
is not duplicated into the release.

Quarterstaff action animations
------------------------------

  Animated Armoury - New Weapons with animations SSE Version
  Author: NickNak
  Nexus: https://www.nexusmods.com/skyrimspecialedition/mods/35978

The author permits reworking, reanimation, and use of the animation sources
with credit. Seven third-person quarterstaff donors are kept in the source
tree: block anticipate, bash intro, power bash, block hit, block idle, equip,
and unequip. The installed mod contains only DAF-generated flight composites,
not the 200+ MiB Animated Armoury package.

Skyrim action composite inputs
------------------------------

Block, bash, draw, sheathe, and shout composites use the matching animations
from the user's legally installed Skyrim Special Edition game as local build
inputs. DAF preserves their upper-body timing, binding, and annotations, then
replaces only root/lower-body tracks with the credited flight pose. Raw game
animation source files are not kept in the repository and are not installed
as a separate source set.

Release composition
-------------------

The release contains 1,167 generated, flight-scoped OAR HKX aliases across the
fallback, unarmed, one-handed, dual-wield, greatsword, axe/warhammer,
quarterstaff, bow, crossbow, magic, and staff families. The exact
original-name coverage is in:

  SKSE\Plugins\DragonAspectFlight-AnimationCoverage.json

SHA-256 hashes for every installed HKX are in:

  SKSE\Plugins\DragonAspectFlight-AnimationHashes.txt

Dragon Aspect Flight does not bundle an ESP, Papyrus scripts, JumpAttack.esp,
Pandora/Nemesis inputs or outputs, Bethesda behavior files, or raw Stances/MCO
assets. Jumping Attack, MCO, Stances, Nemesis, and Pandora are not requirements.
